# StockPredictor
Predict Price of Share based on historical data
# Objective
Build a machine learning model that forecasts Apple's (AAPL) future stock closing price using historical stock market data. The goal is to identify patterns in past prices and evaluate how accurately the model can predict future closing prices.
# Data Needed
I will use historical Apple stock market data, including:
Daily closing prices: To use as the primary variable for predicting future stock prices.
Daily opening, highest, and lowest prices: To understand daily price movements.
Trading volume: To examine whether trading activity is related to price changes.
Historical dates: To identify trends and patterns over time.
I plan to use approximately five years of historical data, which should provide a reasonable starting point for building and testing the model.
